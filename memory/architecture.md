# Architecture

## Spectre

Spectre is a file-based AI engineering operating system running in ~/.spectre/. It provides:

- Operating instructions (AGENTS.md)
- Configuration standards (config/)
- Repeatable workflows (playbooks/)
- Stack knowledge (knowledge/)
- Code templates (templates/)
- Automation scripts (scripts/)
- Persistent memory (memory/)
- Activity logs (logs/)

Spectre does not run as a daemon. It is a knowledge and configuration layer loaded by agentic coding environments (OpenCode, Zen) at session start.
