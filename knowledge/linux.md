# Linux Knowledge

- **Distro**: Fedora
- **Package manager**: dnf
- **Service management**: systemctl
- **Firewall**: firewalld (firewall-cmd)
- **SELinux**: enforcing by default — check with `getenforce`
- **Container runtime**: Podman (docker alias)
- **Logs**: journalctl
- **Process monitoring**: htop, ps, systemd-cgtop
- **Disk**: df -h, du -sh, lsblk
