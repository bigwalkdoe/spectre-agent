# Style Guide

## Python (ruff defaults)

- Line length: 88 characters
- Quotes: double quotes
- Imports: one per line, grouped: stdlib → third-party → local
- Trailing commas: yes where multi-line
- No unused imports or variables (ruff will catch these)

## TypeScript (prettier defaults)

- Line length: 80 characters
- Quotes: single quotes
- Semicolons: always
- Trailing commas: es5
- Arrow parens: always

## General

- 2-space indentation for YAML/TOML.
- Trailing newline at end of every file.
- No trailing whitespace.
